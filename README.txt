تعلّم الصرف — إعداد وتصميم: وائل الخزاعي

طريقة النشر على GitHub Pages:
1) ارفع كل الملفات في هذا المجلد إلى المستودع كما هي (index.html وmanifest.webmanifest وsw.js والأيقونات وLICENSE.txt).
2) من Settings ← Pages اختر Deploy from a branch ثم main و/(root).
3) افتح الرابط https://اسم-المستخدم.github.io/اسم-المستودع/ ؛ على الهاتف اختر «إضافة إلى الشاشة الرئيسية» ليعمل كتطبيق، ويعمل بعد أول زيارة بلا إنترنت (عدا الخطوط التي تُخزَّن بعد أول تحميل).
